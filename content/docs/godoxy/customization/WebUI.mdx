<Callout type="info">
  You can edit, hide, or unhide any app directly in the WebUI by right-clicking
  its card, or double-click a category header to rename it. WebUI edits take
  precedence over Docker labels and route files.
</Callout>

## Properties

Configure dashboard metadata in Docker labels (`proxy.<alias>.homepage`), route files (`homepage:`), or via the WebUI right-click menu:

| Property | Description | Default | Values |
| --- | --- | --- | --- |
| `show` | Show or hide the card on the dashboard | `true` | boolean |
| `name` | Display name | Sanitized alias | string |
| `icon` | Icon reference (see below) | Auto-detected | preset, URL, or relative path |
| `url` | Override click target URL | First public URL | absolute URL |
| `category` | Dashboard section name | Auto-detected (`Docker` / `Others` fallback) | string |
| `description` | Short subtitle | Empty | string |

Click URLs default to the route's first computed public URL — see [Public URLs and dashboard links](../advanced-topics/Domain-Matching#public-urls-and-dashboard-links).

## Icons & Auto-Detection

GoDoxy automatically picks icons and categories from container image names, aliases (stripping common suffixes like `-server`, `-web`, `-app`), the [selfh.st icon directory](https://cdn.jsdelivr.net/gh/selfhst/icons/index.json), and GoDoxy's [preset categories](https://github.com/yusing/godoxy/blob/main/internal/homepage/categories.go).

To set an icon manually:

| Source | Format | Example |
| --- | --- | --- |
| Selfh.st presets | `@selfhst/<filename>.<ext>` | `@selfhst/adguard-home.png` |
| Walkxcode presets | `@walkxcode/<filename>.<ext>` | `@walkxcode/nginx.png` |
| Absolute URL | `https://...` | `https://example.com/icon.png` |
| Relative path on the app | `/path/to/icon.png` | `/-/pwa-icons/logo-192.png` |

## Examples

### Docker Compose

```yaml
services:
  gitlab:
    image: gitlab/gitlab-ce:latest
    container_name: gitlab
    labels:
      proxy.aliases: gitlab, gitlab-reg, gitlab-ssh
      proxy.gitlab: |
        port: 80
        homepage:
          name: GitLab
          icon: "/-/pwa-icons/logo-192.png"
          description: GitLab CE instance
          category: Dev
      proxy.gitlab-reg: |
        port: 5050
        homepage:
          show: false
      proxy.gitlab-ssh: |
        port: "22223:22"
        homepage:
          show: false
```

### Route File

```yaml
# config/services.yml
adgh:
  host: 10.0.2.1
  homepage:
    name: AdGuard Home
    icon: "@selfhst/adguard-home.png"
    description: DNS filtering and ad blocking
    category: Network
```
