---
title: Notifications
description: Send alerts for service health, certificate renewals, config reload errors, ACL summaries, and idle sleep
---

Configure one or more notification providers under `providers.notification` in `config/config.yml` (or via the WebUI config editor). GoDoxy sends alerts for service health changes, TLS certificate renewals, config reload errors, and—when opted in—[ACL summaries](Access-Control#acl-configuration) and [Idle Sleep transitions](Idle-Sleep#sleep-and-wake-notifications).

## Provider Recipes

```yaml
# config/config.yml
providers:
  notification:
    # Gotify
    - name: gotify
      provider: gotify
      url: https://gotify.example.com
      token: ${GOTIFY_TOKEN}

    # Ntfy
    - name: ntfy
      provider: ntfy
      url: https://ntfy.example.com # Base server URL (without topic)
      topic: godoxy
      # token: ${NTFY_TOKEN}        # Optional

    # Discord (built-in webhook template)
    - name: discord
      provider: webhook
      url: https://discord.com/api/webhooks/...
      template: discord

    # Custom webhook (Slack, Pushover, Matrix, etc.)
    - name: slack
      provider: webhook
      url: https://hooks.slack.com/services/...
      mime_type: application/json
      payload: |
        {
          "text": $message,
          "username": "GoDoxy"
        }
```

## Field Reference

| Field | Applies To | Default | Description |
| --- | --- | --- | --- |
| `name` | All | **Required** | Unique provider identifier (referenced by `notify.to` and `acl.notify.to`) |
| `provider` | All | **Required** | `gotify`, `ntfy`, or `webhook` |
| `url` | All | **Required** | Server or webhook URL |
| `format` | All | `markdown` | Message formatting: `markdown` or `plain` |
| `token` | Gotify, Ntfy, Webhook | — | Auth token (required for Gotify; optional Bearer token for Ntfy/Webhook) |
| `topic` | Ntfy | — | Target topic (**required** for Ntfy) |
| `template` | Webhook | — | Predefined payload template (`discord`); omit to use custom `payload` |
| `payload` | Webhook | — | Custom body template (**required** unless `template` is set) |
| `method` | Webhook | `POST` | `GET`, `POST`, or `PUT` |
| `mime_type` | Webhook | auto | Request `Content-Type` header (e.g. `application/json`, `application/x-www-form-urlencoded`) |
| `color_mode` | Webhook | `hex` | Format for `$color`: `hex` (`#ff0000`) or `dec` |

### Custom Webhook Variables

| Variable | Description | Format |
| --- | --- | --- |
| `$title` | Alert title | JSON-escaped string |
| `$message` | Alert body | JSON-escaped string |
| `$fields` | Structured key/value fields | JSON object |
| `$color` | Severity color | Hex (`#ff0000`) or decimal (per `color_mode`) |
