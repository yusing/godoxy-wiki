---
title: Load Balancing
description: Distribute HTTP traffic across multiple backend containers or hosts
---

Routes that share the same `load_balance.link` name are grouped into a single HTTP load balancer.

<Callout type="info">
  Load balancing currently supports HTTP/HTTPS routes only (TCP/UDP load balancing
  is not yet supported).
</Callout>

## Modes & Options

| Property | Description | Default | Values |
| --- | --- | --- | --- |
| `link` | Shared load-balancer group name (becomes the route alias) | **Required** | string |
| `mode` | Distribution strategy | `round_robin` | `round_robin`, `least_conn`, `ip_hash` |
| `sticky` | Pin clients to a backend via cookie | `false` | boolean |
| `sticky_max_age` | Sticky session cookie lifetime | `1h` | Go duration |

Choose a mode:
- **`round_robin`**: Evenly cycles through healthy backends (best default for identical instances).
- **`least_conn`**: Picks the backend with the fewest active connections (best for slow or uneven workloads).
- **`ip_hash`**: Hashes the client IP to keep a client on the same backend. If GoDoxy sits behind Cloudflare or another proxy, enable [Real IP](middlewares/ip-resolution/Real-IP) or [Cloudflare Real IP](middlewares/ip-resolution/Cloudflare-Real-IP) first.

## Examples

### Docker Compose Replicas

```yaml
services:
  whoami:
    image: traefik/whoami
    deploy:
      replicas: 4
    labels:
      proxy.*.load_balance: |
        link: whoami
        mode: round_robin
        sticky: true
        sticky_max_age: 2h
    expose:
      - "80"
```

### Route File (Multiple Hosts / VMs)

```yaml
# config/loadbalancer.yml
api-1:
  host: 10.0.2.1
  port: 8080
  load_balance:
    link: api
    mode: least_conn

api-2:
  host: 10.0.2.2
  port: 8080
  load_balance:
    link: api
    mode: least_conn
```

Across multi-node setups, assign the same `load_balance.link` on containers running on different `godoxy-agent` hosts to balance across servers automatically. Pair load-balanced backends with [Health Monitoring](Health-Monitoring) so unhealthy instances are removed from rotation automatically.
